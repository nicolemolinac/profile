# TELC B1 Pass Coach

Spanish-first TELC Deutsch B1 study app optimized for one objective: pass with the least unnecessary study time.

Built from the user's uploaded Speaking, Writing and Listening study corpus. It prioritizes listening and high-ROI vocabulary, teaches German word order through Spanish 'German brain order', includes browser-based speaking practice, and turns writing into reusable memorized blocks.

## Run

```bash
npm install
npm run dev
```

Open the Vite URL in Chrome for speech recognition support.

## Core modules

- Adaptive pass-readiness dashboard
- High-ROI chunks + Spanish-friendly pronunciation cues
- Sentence builder: Spanish → German-order Spanish → German
- Listening pre-learning + audio + exam-style questions
- TELC speaking Guided / Semi-guided / Exam modes
- Reusable writing templates
- Local progress persistence

The readiness percentage is an internal study-progress indicator, not an official TELC score prediction.
